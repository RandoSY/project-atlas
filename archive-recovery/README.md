# Archive Recovery

This directory records the deep-recovery pass begun 15 September 2026.

Rules:

1. Preserve first; classify second.
2. IAS / Independence Assurance System remains off public GitHub.
3. Third-party forks and imported upstream code remain attributed and are not presented as estate-authored work.
4. Unfinished, superseded, duplicate, or failed experiments are still historical evidence and should not be silently discarded.
5. Exact source snapshots are preferred. When binary transfer is unavailable, preserve a repository-native text edition plus provenance and retain the original in the Library.
6. Missing advertised artifacts are explicitly recorded as missing rather than reconstructed from guesswork.

The goal is not only a clean current portfolio. It is survivability: enough context, source, evidence, and lineage that another competent person can recover what the work was and continue it.
