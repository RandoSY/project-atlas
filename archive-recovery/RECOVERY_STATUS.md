## Hard public/private boundaries

The recovery does **not** treat maximum GitHub exposure as the goal.

- IAS / Independence Assurance implementation material stays off GitHub.
- Protected or mixed IAS-containing visual/document material stays in the protected Library archive.
- DebugWire LIGHTENING implementation is not auto-published; high-level records may be preserved without dumping protected implementation.
- third-party upstream/fork material is attributed and referenced rather than represented as estate-authored work.

## Completion test

The recovery will be considered complete only when every known public project family has one explicit disposition:

- canonical source recovered;
- exact historical snapshot preserved;
- documentation/evidence preserved with source explicitly missing;
- verified upstream/reference only;
- deliberately archived/held;
- duplicate/superseded with provenance retained;
- or deliberately excluded from public GitHub under the protected boundary.

In addition:

- comic/page sets must be recovered or their missing pages explicitly logged;
- major manuals/source/browser apps/datasets/releases must have canonical homes or missing-artifact records;
- Project Atlas activity and migration ledgers must agree with live repositories;
- reconstructed/chunked artifacts must have hashes and reassembly instructions;
- repeated Library/GitHub sweeps should stop producing substantial new public-safe project families;
- a final consolidated unresolved-artifact list must exist.

## How to know the recovery is done

When those conditions are satisfied, Project Atlas will receive a conspicuous root-level closure record:

`RECOVERY_COMPLETE.md`

It will contain the final repository inventory, recovered counts, known losses, protected exclusions, unresolved historical references, and closure date.

**Until `RECOVERY_COMPLETE.md` exists, assume recovery remains active.**
