Mission

TeaTime treats a cup of tea as a measured chemical-and-thermal event. The heart of the exercise is Beer–Lambert: blank light intensity becomes I₀, transmitted tea intensity becomes I, absorbance is A = log₁₀(I₀/I), and concentration follows from A = ε c ℓ when path length and calibration are known. Temperature, mass, and distance make the concentration experiment repeatable and physically interpretable.

Beer–Lambert Core Model

Central relation: A = ε c ℓ

The tea solution is treated optically. The dashboard measures transmitted light intensity after blanking. I₀ is the blank/reference intensity, usually clear water in the same cup or optical cell. I is the transmitted intensity through the tea. Absorbance is computed as A = log₁₀(I₀ / I). If ε and ℓ are known, concentration is c = A / (εℓ). If ε is not known, the dashboard still gives a valid operational tea concentration index, useful for repeatability and comparison.

Optical calibration settings

For a true concentration lab, prepare known tea dilutions, measure A for each, and use the slope as εℓ or ε depending on how the calibration is defined.

Calibration standards

Optional professional extension: create a strong tea stock, dilute it to known fractions such as 0%, 25%, 50%, 75%, and 100%, then measure absorbance. The slope of absorbance vs known concentration becomes the calibration factor. This converts the dashboard from “strength index” to calibrated concentration.

Accurate simulation model

The simulator is now model-first. It generates tea concentration, then computes absorbance and transmitted light through Beer–Lambert. Temperature follows Newton cooling. Extraction follows first-order saturation, optionally accelerated by temperature. Mass includes evaporation drift. Distance is derived from cup geometry and liquid height when those values are supplied.

Model validity notes

This model is accurate enough for instructional TeaTime work when the optical path is fixed and the blank is stable. It becomes increasingly quantitative as calibration improves. The most important real-world error sources are ambient light leakage, tea-particle scattering, moving tea bag shadows, temperature probe lag, and inconsistent optical path length. The model should be validated against real runs before being presented as a virtual twin.

Operator protocol

1. Place empty cup on scale and tare.
2. Install the temperature probe at a repeatable depth and position.
3. Arrange the light jig (LED + sensor) with fixed geometry, record path length ℓ, and set the blank I₀.
4. If using distance, set the level/geometry reference and zero distance.
5. Start the run and mark Blank.
6. Pour hot water and mark Pour.
7. Add the tea bag and mark Steep.
8. Watch absorbance A and concentration/index c rise during steeping; remove the bag at target time and mark Remove.
9. Continue logging through the cooling curve and mark Cool.
10. When drinkable, taste and mark Taste.
11. Save the run and export if needed.

About this dashboard

TeaTime is a compact Beer–Lambert concentration lab supported by temperature, mass, and distance measurements. It supports real instruments or simulator mode. The design goal is an operator-friendly browser resource with tabs, modest charts, storage and retrieval, and an attractive branded face. It is intended as the final dashboard/control-panel layer in your modern setup.
Accepted input: JSON lines like {"tempC":82.1,"lux":210,"massG":248.3,"distCm":3.2} or CSV lines: ms,tempC,lux,massG,distCm
