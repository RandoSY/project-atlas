Teach and investigate

How do you take an ordinary object and turn it into a question students can investigate for themselves?

Curriculum hub

CORE 10

Randall Young pairs low-cost tools with real questions. Students meet the phenomenon first, then bring in a measurement, equation, or instrument when it helps.

New exhibit · Proposed classroom activity

Invent a Sphericity Meter

Give teams a few rocks and a question they can disagree on. The work is to invent a rule, test it, and hand it off to another team, not to guess the teacher’s formula.

02 · Measurement tools and machines

Build and understand instruments

What makes a reading trustworthy when you can change almost everything that carries it?

Existing exhibits

Virtual Instruments

Start with a useful reading. Compare five low-cost instruments and their dashboards, from a voltmeter and frequency meter to an electronic scale, distance meter, and thermometer.

Architecture · Reference implementation

Software-Defined Laboratory

An eScale reading should still mean the same calibrated mass in the same units if the controller, transport, or client changes. SDL separates what the device measures from how data travel and how a browser, logger, or AI client uses them. Changing a sensor may require new calibration; changing a display should not redefine the reading.

A pathway through physical computing

  1. Arduino Revolution. Get a sensor working in a familiar environment, then follow the signal from the pin to the display. The Uno temperature reference is a small starting point.
  2. Wireless Wonders. Keep the reading meaningful as you remove the cable. The Nugget learning ladder and wireless instrument examples show ways into Pico W, ESP32, and BLE work.
  3. LINC. Ask which jobs belong next to the sensor and which belong on the experiment computer. The original LINC let researchers program a laboratory computer and see results locally. The later PDP-12 offered distinct LINC and PDP-8/I instruction modes. Young’s LAB-12 cooling-lab interpretation assigns acquisition to the MSP430G2553 and experiment control to the RP2040 Pico W. It borrows the laboratory workflow, not the instruction sets. The existing source package documents its hardware-verification limits.

Existing robotics resources · Mapping exhibit proposed

Bargain Bin Robotics and ROBOT_EDU resources

Use a robot to measure geometry, heading, and distance as well as to move. Lazy / Patient LiDAR asks whether repeated readings from several known viewpoints can produce a useful map with a cheap range sensor. The design record is available now; a standalone Atlas exhibit is proposed.

Existing code and archives

Computing Observatories

What is the computer actually doing? Young uses Forth, visible processors, and simulators to let learners inspect execution rather than take the result on faith.

03 · Measured human performance

Measure movement and support independence

A movement trace answers different questions depending on what you asked the person to do.

Existing exhibit · Experimental step detection

SQM+ Hallway Observatory

How did I walk over a known course? Start with the marked distance and elapsed time. Use motion traces to investigate cadence and changes in gait, and check candidate steps against an independent count.

New exhibit · Release preview

Fair Fitness Testing

Can I prescribe an effort and tell whether it was performed? Set a target physical output, use motion as evidence of participation, and observe the heart-rate response separately.
