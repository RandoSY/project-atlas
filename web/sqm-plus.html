NOVEMBER 2026 · ENGINEERING CHECKPOINTS

What the latest tests showed

The hallway trials exposed a useful design distinction. A saved recording, a live plot, and a correct step count are three different successes. A plot can freeze while the board keeps recording. A waveform can look periodic while the detector misses events. The dashboard should make those differences visible.

REPEATABLE BY DESIGN

Walk one leg. Know exactly what you timed.

  1. Mark it. Measure a straight 11.00 m course and designate the start and finish. Choose a standing or moving start and keep the same rule across trials. If you use a run-in, don’t count it as timed distance.
  2. Record it. In the simplified workflow, arm the device, begin at GO using the selected start rule, and press A at the finish. Record the same leg with an independent stopwatch or synchronized reference. Use the same hold or mount and orientation each time. Do not pool handheld and torso-mounted trials as if they measured the same motion.
  3. Reset outside the leg. Stop timing before turning. Exclude the countdown, turnaround, waiting, and save time. If you test multileg mode, store each leg’s actual distance and valid walking interval before totaling them.
  4. Repeat five times. Keep each pass as its own record. Note missed marks, dropped samples, delayed presses, and changes in the carry position. Retain the raw IMU file, firmware ID, device start/end times, reference time and count, and candidate event timestamps.

Keep the roles straight. The device’s three accelerometer axes and three gyroscope axes offer different views of motion. The magnitude of acceleration combines three axes, but it does not automatically remove gravity, separate arm swing from a footfall, or prove that a candidate event is a step.

WHAT WOULD CONVINCE US?

The five-pass acceptance test

1 · Check the clockCompare device elapsed time with an independent reference on the same marked leg.
2 · Check the recordConfirm sample counts, time spacing, and file recovery, including during a deliberate browser disconnect.
3 · Check the eventsMatch candidates against a reference observer. Report misses, extras, and uncertainty by pass.

Report per-pass errors and repeatability before claiming validated cadence or step length. Keep Bob, Lurch, and Totter as exploratory motion descriptors. How much vertical, fore–aft, or side-to-side acceleration was recorded is an engineering question, not a diagnosis.
