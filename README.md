## Governance

This estate is a curated working exhibition and source trail, not a dump. Each durable system should have one canonical name, one canonical home, an honest lifecycle state, a known-good proof when one exists, and a clearly stated next action.

Lifecycle labels are `active`, `validated`, `incubator`, `archived`, `upstream`, and `proprietary / off-GitHub`. Source, evidence, and presentation should remain distinguishable.

## Architecture

**CORE** contains the technical and educational foundation: SDL / SUPER / MCP, CORE 10, and the Measured Machine line of Nugget, observatories, simulators, tools, and robotics.

**APPS** applies transparent measurement to human and personal decision problems: FFT, SQM+, Tone Trainer, and PlateLab. Shared infrastructure should be extracted rather than duplicated.

**TRANSMISSION** turns the work into something another person can inherit: Project Atlas, guides, manuals, papers, experiment packages, and visual explainers.

## Protected boundary

**IAS — Independence Assurance System — is intentionally off-GitHub.** It is not part of this public repository estate.

## Working principles

- **Experience Before Equation**
- **Need Before Technology**
- **Not talk, do**
- Prefer durable ideas over particular platforms.
- Preserve broadly; publish selectively.
- Name behavior clearly.
- Do not call copied material verified until its minimum working path has actually been reproduced.
