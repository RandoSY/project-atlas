# Project Card Template

Use one project card per durable named system or project family.

```text
Canonical name:
Short purpose:
Primary domain:
Status: active | validated | incubator | archived | upstream | proprietary/off-GitHub
Visibility:
Canonical home:
Best runnable proof:
Primary hardware / platforms:
Key source components:
Key documents / images:
Dependencies or upstream projects:
Known public-release concerns:
What must be true before release:
Immediate next action:
```

## Guidance

A project card is a control record, not marketing copy. Keep it short, concrete, and current.

- **Canonical name** should be the one name used in Atlas and repository navigation.
- **Status** should describe reality, not aspiration.
- **Best runnable proof** should point to the strongest demonstrated behavior currently available.
- **Canonical home** should identify the one current repository or protected location.
- **Immediate next action** should be small enough to complete without reopening the entire project.
- Board ports, examples, dashboards, and experiments normally remain beneath a durable parent unless they genuinely have their own audience, release cadence, and survival path.
