# Intellectual Estate Migration Queue

Complete and verify a packet before opening a new one.

## P1

1. **Project Atlas control layer** — keep repository roles, lifecycle labels, and migration rules aligned.
2. **SDL baseline** — document one cheap physical endpoint -> host bridge -> AI collaboration -> real measurement path another person can reproduce.
3. **SDL richer reference** — document a richer endpoint and assign it to a numbered SDL release.
4. **One Cup Chemistry starter** — publish a bounded first experiment set with theory, materials, measurement method, and limitations.
5. **CORE 10 canonical map** — preserve `CORE 10 -> Kitchen Inquiry Lab / One Cup Chemistry / NOTHING IS FREE` everywhere.
6. **FFT reference release** — document a reproducible app build, simulator path, defined limits, and complete walking-test workflow.

## P2

7. **SDL + CORE public front door** — one newcomer path from philosophy to first experiment.
8. **Measured Machine preservation batch** — package selected observatory and embedded-tool exemplars without feature expansion.
9. **Bargain Bin Robotics exemplar** — one canonical low-cost robot mission with runnable code and evidence.
10. **Publications consolidation** — assign important papers, manuals, books, guides, and visuals to canonical homes and versions.
11. **Handoff tests** — have another person reproduce the smallest useful success from each flagship package.

## Stop rule

Do not activate a lower-priority project while a P1 packet is open unless it directly unblocks that P1 work.

## Migration rule

Copying files is not validation. Before migrated source is called a current release, confirm its canonical home, public suitability, minimum runnable path, requirements, known limitations, and actual known-good evidence.
